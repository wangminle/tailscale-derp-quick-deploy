# 设计与本地执行记录

- `plans/`：正式需求、设计、实施计划及 achievements 归档，沿用本地保留规则。
- `checkpoints/`：审查、调研、验收、部署记录、日志和历史快照；明确由 Git 忽略，不上传。

这两个目录从项目根目录整体迁入，文件保持在本地。产品使用文档仍放根目录的 `docs/`，任务台账仍为根目录的 `task-list.md`。公开产品文档不要依赖这些本地材料作为必读链接。

新的执行记录写入 `design/checkpoints/`。历史原始日志、快照和命令保留当时内容；其中的绝对路径或脚本相对项目根目录的层级可能反映迁移前的位置，复用时应先核对，不能直接据旧命令操作现网。
